# 🍽️ Canteen Management System

## 📌 Project Overview

The **Canteen Management System** is a web-based application designed to simplify and manage canteen food ordering operations. It allows students and customers to view available food items, place orders, and manage their food purchases online.

The system also provides administrative features to manage food items, customer details, and orders efficiently.

## 🎯 Objectives

- Make food ordering easier and faster.
- Reduce manual work in canteen operations.
- Allow students to order food online.
- Manage food items and prices.
- Track customer orders and order status.
- Provide a user-friendly interface.

## ✨ Features

### 👨‍🎓 Student / Customer
- User registration and login.
- View available food items.
- Browse food categories.
- Add food items to cart.
- Place food orders.
- View order details.
- Track order status.

### 🔐 Admin
- Admin login.
- Manage food items.
- Add, update, and delete food items.
- View customer details.
- Manage customer orders.
- Update order status.
- Monitor canteen activities.
